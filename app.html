Claude access

The tool tries Cowork's built-in Claude first (free with your Cowork session). If that's not available (e.g. you opened this file directly in Chrome), it falls back to calling Anthropic's API with the key you set below.

Heads up: the API key is stored in your browser's localStorage. Anyone with access to this browser profile can read it. Don't paste a production key on a shared machine. Get your key at https://console.anthropic.com/settings/keys.

Usage & budget

Cross-device sync (GitHub Gist)

Your app data (jobs, batches, criteria, resumes) syncs to a private GitHub Gist so it follows you across machines. API keys and gist credentials never sync — they stay only on each device. Auto-sync runs ~3 seconds after every change.

Create one at https://github.com/settings/tokens?type=beta — only the gist scope is required. Or use a fine-grained token with Gist read+write.
Setup flow:
1. On your first device: paste your token, click Create new private gist. Done.
2. On every other device: open the app, go to Settings, paste the same token AND the gist ID from step 1, click Pull from gist now.
3. After that, changes on any device auto-sync; other devices see them on next open or after Pull from gist now.
